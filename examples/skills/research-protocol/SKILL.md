# Research protocol

1. State the exact question and what would count as a good answer.
2. Search broadly first, then narrow to primary sources.
3. Prefer, in order:
   - the paper itself / official documentation,
   - the official repository or changelog,
   - independent benchmarks or reproduced results,
   - secondary summaries.
4. For every important claim, record:
   - claim,
   - source URL,
   - publication date,
   - whether it is verified, self-reported, or uncertain.
5. Separate “what the source says” from “what I infer.”
6. Write long notes to `research/<topic>.md`; return a short brief with the file path.
7. Do not present a vendor claim as an independent result.
